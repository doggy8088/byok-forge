provider

set custom_provider id, api, endpoint
Presets fill base URL, API format, and model defaults. Pick custom for any self-hosted or proxy endpoint.
Referenced as custom_provider:<id>/<model> in mcode -m and defaultModel.
Wire protocol used by mcode: Anthropic Messages, OpenAI Chat Completions, OpenAI Responses, or Google Gemini.
Upstream API endpoint URL (e.g. https://openrouter.ai/api/v1 or https://api.minimax.io/anthropic).
mcode sends apiKey as-is and does not expand ${ENV_VAR}. An env var name is written as a __NAME__ placeholder that the snippet fills in from your shell, and is passed to --api-key-env for the CLI; a literal value is written unchanged.
02

model

model id, capabilities & token limits
Select at launch via mcode -m custom_provider:<id>/<model> or inside TUI with /model.
thinking.effortOptions sets the effort values you can pick in mcode (default = middle item). Without it, a thinking model always gets a generic medium. thinking_config adds an on/off switch (switchable) or pins it (forced_on / forced_off). google-generative-ai ignores effort values.
image / video declare native media input (mcode reads modalities.input). attachment is set automatically when any media type is on.
⟂
⟂
Positive token limits help mcode budget context window and auto-compaction accurately. Leave empty to use mcode's defaults (200,000 / 16,384).
03

target

default model & config path
Default is ~/.minimax/config.yaml (or $MINIMAX_DATA_DIR/config.yaml). Verify with mcode provider list.
