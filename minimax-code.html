provider

set custom_provider id, api, endpoint
Presets fill base URL, API format, and model defaults. Pick custom for any self-hosted or proxy endpoint.
Referenced as custom_provider:<id>/<model> in mcode -m and defaultModel.
Wire protocol used by mcode: Anthropic Messages, OpenAI Chat Completions, OpenAI Responses, or Google Gemini.
Upstream API endpoint URL (e.g. https://openrouter.ai/api/v1 or https://api.minimax.io/anthropic).
Written as ${ENV_VAR} in config.yaml (resolved from environment at runtime without storing secrets on disk) and passed to --api-key-env in CLI commands.
02

model

model id, capabilities & token limits
Select at launch via mcode -m custom_provider:<id>/<model> or inside TUI with /model.
⟂
⟂
Positive token limits help mcode budget context window and auto-compaction accurately.

target

default model & config path
Default is ~/.minimax/config.yaml (or $MINIMAX_DATA_DIR/config.yaml). Verify with mcode provider list.
