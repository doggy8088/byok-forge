provider

set provider id, api, endpoint
Presets set base URL, API type and defaults. Choose custom for your own endpoint.
Used in model selectors as providerId/modelId, e.g. omp --model myprovider/mymodel.
Wire protocol OMP should speak: Chat Completions, Responses, or Anthropic Messages.
API endpoint URL. Ollama example: http://127.0.0.1:11434.
Value is an env var name (read if set) or a literal token. Prefix with ! to run a command and use its stdout.
Enable for proxies that require the standard bearer header (OMP sends provider-native auth by default).

model id + optional limits
Select via omp --model providerId/modelId or /model inside a session.
