Codex Config Forge · generates ~/.codex/<profile>.config.toml BYOK profiles for the OpenAI Codex CLI

    
Codex speaks the Responses API only (wire_api = "chat" was removed) — providers must expose /v1/responses (OpenAI, Azure, Ollama ≥0.9, LM Studio ≥0.3, Groq, vLLM, OpenRouter, xAI). Chat-only providers need a proxy — see the LiteLLM Config Forge. Model names & defaults are best-effort for mid-2026; verify with codex --help. Keys stay in your env, never on disk.
